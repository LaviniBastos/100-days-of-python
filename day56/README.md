# Day 56 — Set Operations
### 🎯 Desafio
Realizar diferentes operações com Sets em Python, os sets são aquelas operações de conjuntos, tal como:

- União (union)
- Interseção (intersection)
- Diferença (difference)
- Diferença simétrica (symmetric_difference)


#### 📚 Aprendizados

1. Sets armazenam valores únicos (sem duplicatas).
Sets são muito utilizados para:
2. remover duplicados
3. comparar coleções
4. realizar operações matemáticas entre conjuntos

##### Principais operações:
- union() = junta os elementos dos conjuntos
- intersection() = elementos em comum
- difference() = elementos exclusivos de um conjunto
- symmetric_difference() = elementos que NÃO estão em ambos
